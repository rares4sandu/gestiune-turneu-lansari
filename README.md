# Gestiune Turneu — descărcare

Program pentru administrarea turneelor de tenis: listele de acceptare,
confirmările, taxele, decontul și documentele de final.

## Descarcă

**[Ultima versiune](../../releases/latest)** — fișierul `Gestiune_Turneu_Setup.exe`.

Dublu-clic pe el. Se instalează doar pentru tine, fără parolă de
administrator. Windows va spune întâi *„Windows protected your PC"*,
pentru că fișierul nu e semnat digital: apeși **Mai multe informații** →
**Rulează oricum**.

Odată instalat, versiunile următoare vin singure — programul îți spune
când apare una și o pune el.

## Ce e aici

Doar fișierele de instalare. Codul programului nu e public.
